# 01. NCBI Data Retrieval

## Objective

Retrieve mitochondrial cytochrome b (CytB/MT-CYB) sequences and complete mitochondrial genomes of *Odocoileus virginianus* from the NCBI GenBank database.

## Methodology

Sequence retrieval was performed using NCBI Entrez Direct (EDirect), targeting CytB gene records and complete mitochondrial genomes.

The workflow includes:

1. Construction of NCBI nucleotide database queries.
2. Retrieval of GenBank accession identifiers.
3. Download of nucleotide sequences in FASTA format.
4. Identification of complete mitochondrial genomes.
5. Verification of gene annotations and sequence lengths.
6. Organization of retrieved sequences for subsequent quality control.

## Software

- NCBI Entrez Direct (EDirect)
- SeqKit
- Python
- Biopython
